# 鸣潮自动任务助手 V2（MingchaoJB）

基于 **Windows 1920×1080 窗口化 + 视觉识别（OpenCV / RapidOCR）+ Win32 `SendInput` 硬件扫描码输入** 的桌面自动任务软件。

## 主要功能（V2）

- **桌面图形控制软件（`MingchaoJB.exe`）**
  - **控制台**：实时查看运行状态、当前状态机阶段、绑定窗口与左上角任务栏 OCR 识别结果，一键切换预设与启停。
  - **预设操作管理**：内置 4 套预设（全自动清任务、纯自动过剧情、高爆发轮切打怪、稳健半自动），支持新建/复制/删除、勾选功能开关与自定义 YAML 战斗连招表，保存后立即生效。
  - **实时日志查看器**：按 `ALL / INFO / WARNING / ERROR` 筛选日志、一键清空、导出日志或直接打开 `logs/` 历史日志与异常截图目录。
  - **模板与调试工具箱**：内置 15 项 UI 模板采集状态清单，一键启动框选采集工具与 ROI/OCR 实时调试预览窗口。
- **V2 核心自动化能力**
  - 剧情自动跳过、二次确认弹窗、对话选项与 `[F]` 交互
  - 自动进战/脱战缓冲、锁敌、协奏满自动切人、大招就绪检测、战后吸收声骸
  - 3D 任务黄标追踪转向、冲刺跑图、钩索 `[T]` 响应与多轮卡死脱困
  - 远距离自动按 `M` 打开大地图定位最近信标快速旅行
  - 左上角无追踪任务时自动按 `J` 打开任务列表按优先级切换下一任务
  - 教学/复活/物品交付弹窗清理，以及解谜/调时间等特殊玩法自动蜂鸣提醒人工接管

## 快速开始

1. 将鸣潮游戏画面设置为 **1920×1080 窗口化**。
2. 双击目录中的 **`MingchaoJB.exe`**（会自动请求管理员权限以向游戏窗口发送硬件按键）。
3. 在软件内切换到 **“模板与调试工具”** 标签页，依次采集关键 UI 模板（至少建议采集 `btn_skip.png`、`icon_f.png`、`quest_marker.png`）。
4. 切回 **“控制台”** 选择合适的操作预设，点击 **“启动脚本 (F8)”** 或在游戏窗口内直接按 **`F8`** 启动/暂停，遇到人工接管提醒处理完后按 **`F7`** 恢复。
